# Glossary

Write each term in your own words. Starter definitions:

| Term | Plain meaning |
| --- | --- |
| Embedding | A short list of numbers that summarizes a signature; similar signatures get nearby embeddings |
| Siamese network | Two copies of the same CNN with shared weights, used to compare two inputs |
| Writer-independent | One model for all writers; works for people not seen in training |
| Skilled forgery | A forger who studied and copied the original signature |
| Contrastive loss | Pulls genuine pairs together, pushes mismatched pairs apart past a margin |
| Triplet loss | Wants anchor closer to positive than to negative by a margin |
| FAR | Forged signatures wrongly accepted |
| FRR | Genuine signatures wrongly rejected |
| EER | Error rate where FAR equals FRR |
| Cross-dataset | Train on one dataset, test on another |
